# Language

Talk to the user in European Spanish (es-ES). Everything that leaves this
machine stays in English: code, comments, docs, commits, issues, PRs and
review comments.

## Agent skills

### Issue tracker

Issues live in GitHub Issues for `aulasoftwarelibre/ucopunto-2026-template`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
